Ejercicio 2 — Lista de tareas (Todo List)
Sé que parece básico pero es el ejercicio más común en entrevistas técnicas frontend de cualquier nivel. En 40 minutos te pueden pedir exactamente esto.
Tiene que tener:

Un input para escribir una tarea
Un botón para añadirla
La lista de tareas añadidas
Un botón para eliminar cada tarea
