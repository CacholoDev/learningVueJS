Ejercicio 6 — Panel de notificaciones
Una campanita arriba a la derecha con un número de notificaciones sin leer
Al hacer click se abre una lista de notificaciones. 
Cada notificación tiene título, mensaje y si está leída o no. 
Al hacer click en una notificación se marca como leída y el contador baja.
Hay un botón "marcar todas como leídas".
