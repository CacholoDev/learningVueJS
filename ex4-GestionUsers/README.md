Ejercicio 4 — Gestión de usuarios

Una lista de usuarios hardcodeados con nombre, email y activo (true/false)
Mostrar cada usuario con un badge verde si está activo y rojo si no
Un botón para cambiar el estado activo/inactivo de cada usuario
Un contador arriba que diga cuántos usuarios hay activos en total
Un filtro con dos botones — "Todos", "Activos", "Inactivos"
